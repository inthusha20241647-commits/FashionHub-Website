# 👗 FashionHub

FashionHub is a responsive fashion website built using **HTML, CSS, and JavaScript**. The project provides a simple and attractive interface for browsing fashion products, exploring collections, and contacting the website.

## 🌐 Live Demo

🔗 https://inthusha20241647-commits.github.io/FashionHub-Website/

## 📌 About the Project

FashionHub is a front-end fashion website created to practice and demonstrate web development concepts such as:

* Responsive web design
* Navigation bars
* Mobile sidebars
* Product search
* Product filtering
* Image-based product cards
* Contact forms
* CSS layouts and styling
* JavaScript DOM manipulation

## ✨ Features

### 🏠 Home Page

* FashionHub navigation bar
* Fashion banner
* Brand showcase
* Customer experience section
* New arrivals
* Sales section
* Limited-time offer
* Newsletter subscription section
* Footer with social media icons

### 🛍️ Collections Page

* Product collection display
* Product search functionality
* Search products by name
* Occasion categories
* Colour categories
* Arrival categories
* Product cards with images and prices

### 🔎 Product Search

Users can search for products by entering text in the search box.

The JavaScript checks the product names and hides products that do not match the entered search value.

### 📱 Responsive Navigation

The website includes a mobile navigation sidebar.

Users can:

* Open the sidebar using the menu icon
* Close the sidebar using the close button

## 🚀 How to Run

1. Clone the repository.

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project folder in VS Code.

3. Open `index.html`.

4. Run the project using **Live Server** or open `index.html` directly in your browser.
